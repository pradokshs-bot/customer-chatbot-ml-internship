# 🤖 Customer Service Chatbot using NLP and Machine Learning

## 📌 Project Overview

The Customer Service Chatbot is an AI/ML-based project developed using Python and Natural Language Processing (NLP).

The chatbot understands basic customer queries, identifies the user's intent using a Machine Learning model, and provides suitable automated responses.

The main objective is to reduce manual customer support efforts and provide quick assistance for common customer questions.

## 🎯 Objectives

- Develop an automated customer support chatbot.
- Understand customer queries using NLP techniques.
- Classify customer messages into different intent categories.
- Generate relevant responses automatically.
- Provide an interactive chatbot interface.

## ⚙️ Working Methodology

1. **Dataset Creation:** Prepare customer questions and categorize them into different intents.
2. **Text Processing:** Convert customer messages into numerical features using TF-IDF.
3. **Model Training:** Train a Logistic Regression classifier.
4. **Intent Prediction:** Predict the intent of incoming customer messages.
5. **Response Generation:** Select an appropriate predefined response.
6. **User Interface:** Use Gradio to provide an interactive chatbot experience.

## 🧠 Machine Learning Algorithm

**Logistic Regression**

The project uses Logistic Regression to classify customer queries into predefined intent categories.

TF-IDF (Term Frequency–Inverse Document Frequency) is used to convert text messages into numerical representations before classification.
